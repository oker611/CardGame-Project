# 离线遗传算法（实验性）

此目录包含用于优化锄大地AI策略参数的**遗传算法实验代码**。

⚠️ **注意**：该模块未在主项目中使用，仅作为探索性研究保留。

## 说明

- 这是一个独立的 Maven 模块，可单独编译运行
- 用于离线训练蒙特卡洛AI的最优参数组合
- 完整说明详见 [offline-ga/README.md](offline-ga/README.md)

## 快速开始

```bash
cd offline-ga
mvn clean compile
mvn exec:java -Dexec.mainClass="com.example.cardgame.ga.Main"
```

## 未使用原因

1. **计算开销过大**：完整训练需要数小时，不适合移动端
2. **参数空间复杂**：12个参数容易陷入局部最优
3. **规则策略更优**：项目中设计的残局强制压牌、阶段管理等规则策略在实际对战中表现更稳定，优于遗传算法优化的参数
4. **蒙特卡洛已足够**：手动调参的AI在实际对战中表现良好

## 技术价值

虽然未投入实际使用，但展示了：
- 使用遗传算法优化博弈AI的可行性
- 完整的遗传算法实现流程（选择、交叉、变异）
- 为手动调参提供了参考方向
