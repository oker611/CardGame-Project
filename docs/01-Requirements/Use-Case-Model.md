## 参与者 (Actors)

| 参与者 | 说明 |
|--------|------|
| 人类玩家 (Human Player) | 通过 UI 交互操作游戏，包括选牌、出牌、过牌、设置规则 |
| AI 玩家 (AI Player) | 系统自动决策出牌或过牌，支持贪心/蒙特卡洛/自适应三种策略 |
| 蓝牙设备 (Bluetooth Device) | 通过蓝牙 RFCOMM 协议进行跨设备通信，支持 HOST/CLIENT 角色 |
| Vivo 蓝心大模型 (Vivo LLM) | 云端大语言模型服务，用于对手风格分析 |

## 用例清单

### 游戏核心
| 编号 | 用例 | 说明 |
|------|------|------|
| UC-01 | 开始游戏 | 玩家选择规则和难度后启动新游戏 |
| UC-02 | 出牌 | 玩家选择手牌并打出，需符合牌型且能压过上家 |
| UC-03 | 过牌 | 玩家放弃本轮出牌权 |
| UC-04 | 查看游戏状态 | 查看当前牌局信息（手牌、上家出牌、剩余牌数） |
| UC-05 | 游戏结算 | 一局结束后展示排名 |
| UC-06 | 选择规则 | 南方/北方规则切换 |
| UC-07 | 选择 AI 难度 | EASY/MEDIUM/HARD/ADAPTIVE |
| UC-08 | 切换道具 | 记牌器/牌型提示/透视开关 |

### 发牌与回合
| UC-09 | 发牌 | 52 张牌随机分配，标记♦3首出 |
| UC-10 | 回合管理 | 按顺序切换出牌权 |

### 蓝牙联机
| UC-11 | 创建蓝牙房间 | HOST 创建房间等待加入 |
| UC-12 | 搜索蓝牙设备 | 扫描附近可用设备 |
| UC-13 | 加入蓝牙房间 | CLIENT 连接 HOST |
| UC-14 | 蓝牙出牌同步 | 跨设备同步出牌动作 |
| UC-15 | 蓝牙过牌同步 | 跨设备同步过牌动作 |
| UC-16 | 游戏结束同步 | HOST 广播游戏结束消息 |
| UC-17 | HOST 分配角色 | 为加入的 CLIENT 分配 P2/P3/P4 身份 |
| UC-18 | 断线重连 | CLIENT 掉线后自动重连并恢复状态 |

### 可靠性
| UC-19 | 心跳保活 | 5s 间隔心跳检测在线状态 |

### AI 增强
| UC-20 | 对手风格分析 | 调用 LLM 分析人类玩家出牌风格 |
| UC-21 | 自适应 AI 对抗 | 根据分析结果自动调整 AI 策略 |
