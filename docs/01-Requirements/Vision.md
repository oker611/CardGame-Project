# Vision

## 产品概述

本项目开发了一套基于锄大地（Big Two）规则的多人卡牌游戏系统，支持 Android 移动端运行。

系统提供完整的单人练习与四人联机对战体验，集成三层 AI 决策引擎（贪心→蒙特卡洛→自适应）和大语言模型对手风格分析能力。

## 核心能力

- **完整锄大地规则引擎**：识别 10 种牌型，支持南方/北方双规则体系，首轮♦3强制、跨牌型压制、连续 3 人 Pass 清空桌面
- **四人多人对战**：单机模式（1 Human + 3 AI）与蓝牙联机模式（1 HOST + 3 CLIENT，支持 Human/AI/Remote 任意组合）
- **三层 AI 体系**：贪心策略（3 风格变体）、蒙特卡洛模拟、自适应策略（分析人类风格并自动调整）
- **蓝牙可靠通信**：16 种消息类型，心跳保活（5s 间隔/15s 超时），ACK 可靠投递（3s×3次），断线重连（指数退避 2/4/8/16/30s）
- **LLM 集成**：接入 Vivo 蓝心大模型进行对手风格智能分析，异步调用不阻塞主线程
- **事件驱动架构**：全局 EventBus 解耦 UI / AI / 蓝牙三大模块

## 技术栈

| 层级 | 技术 |
|------|------|
| 语言 | Java 8 |
| 平台 | Android SDK (API 21+, 兼容 4.4+) |
| 通信 | Bluetooth RFCOMM |
| 网络 | OkHttp (LLM API 调用) |
| 序列化 | Gson (JSON 编解码) |
| AI | 蒙特卡洛树搜索 + 遗传算法参数优化 |
| LLM | Vivo 蓝心大模型 (DeepSeek-V3.2) |
| 测试 | JUnit 4 |
| CI/CD | GitHub Actions |

## 设计目标

- **可扩展性**：14 个接口支撑完整依赖注入体系，新增 AI 策略或蓝牙模块无需修改现有代码
- **可测试性**：123 个单元测试覆盖引擎/规则/AI/网络层，核心逻辑可在 JVM 纯环境运行
- **可维护性**：6 种 GoF 设计模式，0 反射，0 静态可变状态，异常精确化至具体类型

## 项目规模

约 100 个 Java 类，覆盖 11 个功能包，5 个 Sprint 迭代（约 10 周），5 人团队协作开发。
